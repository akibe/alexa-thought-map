# Go On — upload and submission text

## Video title

Go On — An AI that listens | Alexa+ Hackathon Demo

## Video description

I was still thinking when the answer arrived.

Go On explores a different rhythm: brief acknowledgments while you talk, and a map only when you ask. Original words stay available as their relationships change—from topics to possible shared roots, then one place to begin.

This video combines illustrated conversation with a recording of our working local MCP web simulator. The demo uses 16 synthetic statements and handwritten fixed analysis; it makes no live model calls. Voice interaction is staged, and live Bedrock quality, speech recognition and Alexa+/Echo behavior remain unverified.

Built with Node.js, SQLite, MCP and MCP Apps. The repository includes the asynchronous Bedrock integration and packaged root-reasoning Skill. The fixed demo runs locally without AWS credentials.

Synthetic narration generated locally with Kokoro v1.0 (Apache-2.0), using kokoro-onnx (MIT). No voice cloning, stock footage or background music.
