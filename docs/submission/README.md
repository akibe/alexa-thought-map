## 原稿で守る一本の流れ

返事や助言が早すぎると、考えの続きが消える。だから、まず聞く。本人の「Show me」で初めて、言葉を地図にする。原文を残したまま、話題から共通する根へと組み替え、一つの次の行動が見えてくる。

「返事をしないAI」は冒頭の逆説として残し、主コピーは利用者が選んだ「聞いてくれるAI。」。「Go On」は10月24日に暫定採用。名称探索をこれ以上広げず、提出制作を優先する。

## 証拠と演出

- 実デモ：独自Webシミュレーターから実MCP通信、MCP App表示、段階操作、根と原文の参照。
- 固定データ：架空の英語16件と手作りの分析結果。ライブ推論ではない旨を画面と本文に明記。
- 音声会話：想定体験を示す演出。音声認識・Alexa実機動作として見せない。
- 未検証：実Bedrockの推論品質、実音声/Alexa+/Echo、複数日にわたる利用効果。
- UI内のThought Mapは実装時の名称。Go Onは同じ作品の提出用タイトルとして審査手順に説明。
